= Changelog

Notable changes to anchor.

anchor and SPEC.adoc are versioned separately. SPEC.adoc defines what anchor
does and what it refuses to do.

== 1.0.2

Documentation and fixture prose cleanup.

This release changes words, not behavior. It rewrites README.adoc,
SPEC.adoc, CHANGELOG.adoc, source comments, docstrings, test descriptions,
and fixture prose for shorter and clearer language.

It also keeps Makefile recipes tab-indented, as make requires.

No API, output, parser, graph, command, or SPEC behavior changed.

== 1.0.1

A bug fix allowed by the freeze.

=== `generated-page` and `tag-id` are exported

SPEC.adoc defers per-tag pages. It does not reject them. It says a site that
wants per-tag pages can write an emitter:

"That is what the interface is for, and it is why per-tag pages are deferred
rather than missing."

That interface was incomplete. `*emitters*` was exported, but
`generated-page` was not. An emitter that writes a page needs
`generated-page`, so site code outside the package could not use the promised
extension point.

`tag-id` had the same problem. A layout that links a tag to the tag index must
use the same identifier that the index uses. Without `tag-id`, the layout had
to reimplement the rule and hope both rules stayed equal.

No function behavior changed. The export list now matches the interface that
SPEC.adoc already described. This is therefore a fix, not a feature.

== 1.0.0

First release.

This is also the last release that adds features. Every section that SPEC.adoc
marks `v1` is built. That is what SPEC.adoc defines as 1.0. The freeze is now
in force.

anchor now takes only bug fixes and changes required to track cl-adoc's
released interface.

=== Building a site

A directory that contains `index.adoc` is a page. Its path is its URL.
Discovery is therefore a filesystem walk. Nothing must be configured.

anchor parses pages, builds the graph once, resolves references, and then
renders output.

The graph answers chronology, section structure, and taxonomy. A page's
parent is the nearest ancestor directory that is also a page. A directory with
no document is only a path component, not a section.

`_anchor.lisp` configures its directory and all directories below it.
Configuration is merged parent to child. The file is evaluated, not read as
data. Earlier forms can therefore define the layout function named by the last
form.

Drafts use `:draft:`. Drafts are left out of the graph, not only out of the
output. A published page that links to a draft therefore has a broken
reference, and anchor reports it.

=== Output

Layouts are functions. A layout receives a page and a site and returns HTML as
s-expressions. anchor serializes those forms itself.

Head-tag composition is a list of functions that return forms. Because the
head is data, a site can build, filter, and test it.

Emitters are functions from a site to output files. Four emitters ship:
an Atom feed, `sitemap.xml`, `robots.txt`, and one `/tags/` page.

The feed contains articles, not sections. A page with children is an index of
other pages.

If a site has no `:base-url`, anchor does not emit a feed, sitemap canonical
link, or Open Graph tags. There is no valid feed with relative entry IDs.
Emitting a broken feed is worse than emitting none.

=== References and media

anchor resolves each link and image once before rendering. It writes the
resolved target back onto the node. It does not rewrite rendered output.

A relative target is resolved from the page's directory upward to the site
root. Colocated media is found first. `_media/` is found later. Colocated and
shared assets therefore use one rule, not two.

=== Commands

anchor ships three commands:

----
anchor build
anchor serve
anchor check
----

`check` reports missing references, undated pages, orphaned files, duplicate
content, page weight, and reference resolutions. It exits non-zero when the
site is wrong.

`serve` keeps the graph in the Lisp image on its own thread. The REPL that
started it stays usable. A recompiled layout appears on the next request.

The server speaks enough HTTP to serve a directory to a browser on loopback.
It does no more.

=== Known limits

A stylesheet is named by a layout, not by a document. `check` therefore
reports it as an orphan. The reference relation covers what documents point
at. Orphans are reported and never deleted.

anchor needs cl-adoc 0.2.0 or later for description lists.
